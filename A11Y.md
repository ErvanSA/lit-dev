# Audit Aksesibilitas — wec-ui

Tinjauan aksesibilitas (pivot brand Telkomsel — komponen aktif: `wec-button`).
Metode: tinjauan pola ARIA/keyboard + unit test interaksi (Vitest + happy-dom).

## `wec-button`

| Aspek          | Status | Detail                                                                            |
| -------------- | ------ | --------------------------------------------------------------------------------- |
| Keyboard       | ✅     | Enter/Space native dari `<button>` internal                                       |
| Focus-visible  | ✅     | `outline: 2px solid var(--wec-color-border-focus)`, offset 2px                    |
| State disabled | ✅     | `disabled` native (non-fokusabel, non-interaktif) + teks disabilitas dari token   |
| Kontras        | ✅     | `#FF0025` ↔ teks putih; disabled `#E9E8ED` ↔ `#99A0A7` (pasangan token)           |
| Event          | ✅     | `click` composed dari `<button>` internal — wrapper React/Angular menerima native |

## Catatan lanjut

- Verifikasi screen reader nyata (NVDA/VoiceOver) menyusul bersama QA.
- Komponen berikutnya wajib mengikuti pola yang sama: state via atribut reflect,
  fokus ring token, pasangan warna semantik, wiring ARIA terpusat.
