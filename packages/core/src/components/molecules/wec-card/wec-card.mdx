# wec-card

Wadah konten dengan slot `header`, default, dan `footer`. Aktifkan prop
`interactive` untuk gaya hover/press pada kartu yang bisa diklik — tetap
sertakan kontrol fokusabel di dalamnya bila kartu adalah target aksi.

<Canvas of={CardStories.Playground} />

<ArgTypes of={CardStories} />

## React

```tsx
import { Card, Button } from '@wec-ui/react';

export function Profil() {
  return (
    <Card>
      <h3 slot="header">Profil</h3>
      <p>Data akun Anda…</p>
      <div slot="footer">
        <Button size="sm" variant="secondary">
          Tutup
        </Button>
      </div>
    </Card>
  );
}
```

## Angular

```ts
import 'wec-ui/define/wec-card.js';
```

```html
<wec-card>

```
