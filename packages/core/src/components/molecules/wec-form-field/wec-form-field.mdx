# wec-form-field

Pembungkus kontrol form: label + hint + error + slot kontrol. Saat prop
`error` terisi, hint otomatis digantikan dan error diumumkan screen reader
(`role="alert"`).

Label, hint, dan error dihubungkan otomatis ke kontrol berslot:

- kontrol `wec-*` → properti `labelledBy`/`describedBy`;
- kontrol native (`<input>` biasa) → atribut `aria-labelledby`/`aria-describedby`.

## React

```tsx
import { FormField, Input } from '@wec-ui/react';

export function EmailField() {
  return (
    <FormField label="Email" hint="Gunakan email kantor" required>
      <Input type="email" placeholder="nama@perusahaan.co.id" />
    </FormField>
  );
}
```

Menampilkan error:

```tsx
<FormField label="Email" error="Email wajib diisi">
  <Input type="email" invalid />
</FormField>
```

## Angular

```ts
import 'wec-ui/define/wec-form-field.js';
import 'wec-ui/define/wec-input.js';
```

```html
<wec-form-field label="Email" hint="Gunakan email kantor" [required]="true">
  <wec-input type="email"></wec-input>
</wec-form-field>
```
