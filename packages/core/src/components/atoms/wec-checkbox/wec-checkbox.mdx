# wec-checkbox

Checkbox dengan label dari slot. Keyboard: `Space` untuk toggle, fokus
mengikuti `:focus-visible` dengan ring token.

<Canvas of={CheckboxStories.Playground} />

<ArgTypes of={CheckboxStories.meta} />

## Events

| Event        | detail               | Kapan          |
| ------------ | -------------------- | -------------- |
| `wec-change` | `{ checked, value }` | Status berubah |

## React

```tsx
import { Checkbox } from '@wec-ui/react';

<Checkbox onWecChange={(e: CustomEvent<{ checked: boolean }>) => setAgree(e.detail.checked)}>
  Setuju dengan syarat dan ketentuan
</Checkbox>;
```

## Angular

```ts
import 'wec-ui/define/wec-checkbox.js';
```

```html
<wec-checkbox (wec-change)="onChange($event)">Setuju</wec-checkbox>
```
