# wec-input

Input teks satu baris. Gunakan bersama `wec-form-field` untuk label + hint +
error (wiring ARIA dilakukan otomatis).

<Canvas of={InputStories.Playground} />

<ArgTypes of={InputStories.meta} />

## Events

| Event        | detail      | Kapan                          |
| ------------ | ----------- | ------------------------------ |
| `wec-input`  | `{ value }` | Setiap perubahan saat mengetik |
| `wec-change` | `{ value }` | Nilai commit (blur / enter)    |
| `wec-focus`  | —           | Input mendapat fokus           |
| `wec-blur`   | —           | Input kehilangan fokus         |

## React

```tsx
import { Input } from '@wec-ui/react';

export function Cari() {
  return (
    <Input
      type="search"
      placeholder="Cari…"
      onWecInput={(e: CustomEvent<{ value: string }>) => console.log(e.detail.value)}
    />
  );
}
```
