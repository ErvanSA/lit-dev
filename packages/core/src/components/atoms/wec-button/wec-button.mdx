# wec-button

Tombol design system wec-ui — brand **Telkomsel** (font Poppins, pill merah).

| Varian    | Tampilan                                            |
| --------- | --------------------------------------------------- |
| `primary` | Latar merah `#FF0025`, teks putih bold              |
| `outline` | Latar putih, border + teks merah `#FF0025`          |

`disabled` adalah **state** (bukan varian): latar `#E9E8ED`, teks `#99A0A7`,
non-interaktif.

<Canvas of={ButtonStories.Playground} />

<ArgTypes of={ButtonStories} />

Interaksi klik tampil di panel **Actions**.

## React

```tsx
import { Button } from '@wec-ui/react';

<Button variant="primary" onClick={() => gantiNomor()}>Ganti Nomor</Button>
<Button variant="outline" onClick={() => unduhKontrak()}>Unduh Kontrak</Button>
<Button variant="primary" disabled>Cek</Button>
```

## Angular

```ts
import { WecUiModule } from '@wec-ui/angular';

@Component({
  standalone: true,
  imports: [WecUiModule],
  schemas: [CUSTOM_ELEMENTS_SCHEMA],
  template: `<wec-button variant="outline" (click)="unduh()">Unduh Kontrak</wec-button>`,
})
```

## Next.js

Sama dengan React — wrapper sudah `'use client'`.
