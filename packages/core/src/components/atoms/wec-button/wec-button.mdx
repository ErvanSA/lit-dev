# wec-button

Tombol dasar design system. Varian: `primary` (aksi utama), `secondary` (aksi
pendamping), `ghost` (aksi ringan), `danger` (aksi destruktif). Prop `loading`
menampilkan spinner dan menahan interaksi; prop `disabled` menonaktifkan tombol.

<ArgTypes of={ButtonStories} />

## React

```tsx
import { Button } from '@wec-ui/react';

export function Simpan() {
  return (
    <Button variant="primary" size="md" onWecClick={() => console.log('klik')}>
      Simpan
    </Button>
  );
}
```

Ikon prefix/suffix lewat slot:

```tsx
<Button>
  <wec-icon slot="icon-start" name="check" />
  Simpan
</Button>
```

## Angular

```ts
import { CUSTOM_ELEMENTS_SCHEMA, Component } from '@angular/core';
import 'wec-ui/define/wec-button.js';

@Component({
  selector: 'app-simpan',
  standalone: true,
  schemas: [CUSTOM_ELEMENTS_SCHEMA],
  template: `<wec-button variant="primary" (click)="simpan()">Simpan</wec-button>`,
})
export class SimpanComponent {
  simpan() {
    // ...
  }
}
```

## Next.js (App Router)

Saat memakai `@wec-ui/react`, banner `'use client'` sudah otomatis. Tanpa
wrapper, impor definisi di dalam Client Component:

```tsx
'use client';
import 'wec-ui/define/wec-button.js';
```

## Drupal 10/11

`wec_ui.libraries.yml`:

```yaml
wec_ui:
  version: 0.1.0
  css:
    theme:
      tokens/tokens.css: {}
  js:
    dist/define/wec-button.js:
      type: module
  dependencies:
    - core/drupal
```

Twig:

```twig
{{ attach_library('wec_ui/wec_ui') }}
<wec-button variant="primary">{{ 'Simpan'|t }}</wec-button>
```

> Muat `tokens.css` **sekali per halaman**; definisi komponen (`define/*.js`)
> cukup sekali per library.
