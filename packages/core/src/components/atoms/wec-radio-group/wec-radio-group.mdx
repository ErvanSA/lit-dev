# wec-radio-group

Grup radio — membungkus `<input type="radio">` native yang di-slot. Navigasi
panah antar opsi dikerjakan browser secara native; grup menyediakan
`role="radiogroup"`, wiring ARIA dari `wec-form-field`, dan event `wec-change`.

<Canvas of={RadioGroupStories.Playground} />

<ArgTypes of={RadioGroupStories} />

## Events

| Event        | detail      | Kapan                            |
| ------------ | ----------- | -------------------------------- |
| `wec-change` | `{ value }` | Radio berslot berubah (pengguna) |

Interaksi di Playground tampil di panel **Actions**.

## React

```tsx
import { FormField, RadioGroup } from '@wec-ui/react';

<FormField label="Paket pengiriman">
  <RadioGroup value="reguler" onWecChange={(e) => setPaket(e.detail.value)}>
    <label>
      <input type="radio" name="paket" value="reguler" /> Reguler
    </label>
    <label>
      <input type="radio" name="paket" value="ekspres" /> Ekspres
    </label>
  </RadioGroup>
</FormField>;
```

## Angular

```ts
import 'wec-ui/define/wec-radio-group.js';
```

```html
<wec-radio-group value="reguler" (wec-change)="onChange($event)">
  <label><input type="radio" name="paket" value="reguler" /> Reguler</label>
  <label><input type="radio" name="paket" value="ekspres" /> Ekspres</label>
</wec-radio-group>
```
