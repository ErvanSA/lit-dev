# wec-ui — Design System Internal

Design system berbasis **Web Components (Lit 3)** untuk dipakai lintas
**Angular ≥ 18, React, Next.js ≥ 14 (App Router), dan Drupal 10/11** —
brand **Telkomsel** (font Poppins & Telkomsel Batik).

## Status

✅ **Pivot brand Telkomsel.** Token warna & font diganti ke brand Telkomsel
(lihat `tokens/tokens.json` + `tokens/build/fonts.css`). Komponen lama
dihapus; saat ini komponen yang tersedia:

| Level | Komponen    | Varian/State                    |
| ----- | ----------- | ------------------------------- |
| Atoms | `wec-button` | `primary`, `outline`, `disabled` |

Komponen lain menyusul sesuai desain.

## Tema (theming)

Seluruh styling komponen memakai CSS custom properties berprefix `--wec-`
(lihat `tokens/tokens.json`). Muat `tokens.css` + `fonts.css` sekali per
aplikasi. Dark mode: set `data-theme="dark"` pada `<html>`.
