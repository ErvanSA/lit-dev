# wec-ui — Design System Internal

Design system berbasis **Web Components (Lit 3)** dengan pola **Atomic Design**, untuk dipakai
lintas **Angular ≥ 18, React, Next.js ≥ 14 (App Router), dan Drupal 10/11**.

## Status

✅ **Fase 0 — Fondasi** dan **Fase 1 — MVP** selesai. Komponen tersedia:
`wec-button`, `wec-input`, `wec-checkbox`, `wec-icon`, `wec-badge` (atoms) dan
`wec-form-field`, `wec-card` (molecules) — dengan wrapper `@wec-ui/react`,
docs MDX per framework, dan test lengkap. Rencana lanjut: **Fase 2**
(generator Angular, komponen lanjutan, audit a11y + visual regression).

## Struktur komponen

| Level     | Komponen                                                                  | Status    |
| --------- | ------------------------------------------------------------------------- | --------- |
| Atoms     | `wec-button`, `wec-input`, `wec-checkbox`, `wec-icon`, `wec-badge`        | ✅ Fase 1 |
| Molecules | `wec-form-field`, `wec-card`                                              | ✅ Fase 1 |
| Lanjutan  | `select`, `textarea`, `radio-group`, `switch`, `tabs`, `modal`, `tooltip` | Fase 2    |

## Tema (theming)

Seluruh styling komponen memakai CSS custom properties berprefix `--wec-` (lihat
`tokens/tokens.json`). Dark mode aktif dengan atribut global:

```js
document.documentElement.dataset.theme = 'dark';
```

atau set `data-theme="dark"` pada elemen pembungkus aplikasi.
